# Managed job-data APIs for Taco

Reviewed October 8, 2026 from provider-owned pages. No accounts, trials, API keys, paid requests, live job queries, or vendor contacts were used. Published coverage and freshness claims remain untested. “Records/jobs per day” are provider ingestion or catalog counts, not proof of complete market coverage.

## Recommendation

Pilot **Fantastic.jobs** and **TheirStack** as additive supply behind Taco's existing source policy and normalized evidence contract. Fantastic.jobs has the clearest documented hourly feed plus modified/expired endpoints, with a $95 tier covering 20,000 jobs/month. TheirStack gives Taco a source-visible broad-market comparison and an explicit license for user-facing public job display, at $49 for 1,500 API credits. TheirStack's entry unit cost is higher; its source visibility and explicit terms help evaluate its incremental value. Compare unique, usable jobs per dollar after dedupe, not raw response volume.

Rights and product fit still require validation before selecting either provider. Taco should retain provider/source IDs, source and apply URLs, complete description, original publication timestamp, provider discovery/observation time, closure status, and compensation currency/unit separately. Treat inferred fields as uncertain. Evaluate with identical role/location/date queries against current Taco supply; count only listings that survive Taco trust policy and have a usable application path. Results describe the bounded retrieval set, not all vacancies.

## Integration and evaluation notes

Fantastic.jobs is the lowest-friction freshness adapter: poll its one-hour active ATS endpoint on schedule, request descriptions explicitly (`description_format=text`), and paginate by cursor. Expired-job reconciliation is a paid-plan feature; the Modified Jobs API starts at the **$175/month Pro-50k tier**, not the $95 entry tier. It also has a job-board endpoint. Sanitize HTML if requested; keep AI-enriched fields separate from source facts. Its published `description_text` field and schema show full-description support, but a sample/schema is not a guarantee of completeness per record.

TheirStack is a simple POST adapter with one credit per returned job, date-bounded query filters and local pagination. Webhook job events also consume credits and are not deduplicated against API retrieval. Its `scraping_source` means where the provider first found the job, not every site that published it; direct-source attribution and canonical/apply URLs should remain distinct. Its source list can help compare against Taco's current Greenhouse/Lever/Ashby boards, but those source totals are not counts of Taco-new jobs.

JSearch is useful as a low-cost query-time comparator or gap-filler, not durable supply: repeated user queries spend requests, and Google-indexed listings can duplicate direct source records. Coresignal is a credible alternative if a free-trial sample establishes broad multi-source—not just Base Jobs—coverage and the provider confirms both billing and display rights. JobsPikr remains quote-dependent until docs and license are supplied.
